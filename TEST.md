# Evaluación de Conocimientos: GitHub y Markdown
 
## 1. Conceptos Generales
**¿Qué es un archivo Markdown y para qué sirve?**
> Es un documento de texto que utiliza una sintaxis simple para formatear contenido como títulos, listas, enlaces e imágenes, convirtiéndose en HTML para su ver desde la web.
 
**¿Cuál es el propósito del archivo README.md en un repositorio de GitHub?**
*Es un repositorio actúa como la guía de un proyecto, explicando su propósito, instrucciones de instalación, uso, contribución y otros detalles esenciales para que usuarios y colaboradores lo comprendan rápidamente sin revisar el código.*

## 3. Flujo de Trabajo en GitHub Desktop
**¿Qué diferencia hay entre hacer un "Commit" y hacer un "Push"?**
* **Commit:**  Guarda los cambios en tu repositorio local. En la base de datos de Git que tienes en tu máquina.
* **Push:** Envía tus commits locales al repositorio remoto (por ejemplo, GitHub, GitLab, Bitbucket). En el servidor remoto, accesible para otros colaboradores.
 
**¿Para qué sirve el botón "Fetch Origin"?**
> El botón “Fetch Origin” sirve para traer los cambios más recientes del repositorio remoto (llamado origin) a tu repositorio local, pero sin mezclarlos todavía con tu rama actual.
